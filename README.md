## 评分方法：9项标准，总分100

| 标准 | 权重 | 衡量内容 |
| --- | --- | --- |
| M01 · 文化主题覆盖 | 9% | 覆盖8个以上学科领域 |
| M02 · 课程结构与学习路径 | 16% | 多阶段课程、进度与知识巩固 |
| M03 · 下班后使用便利性 | 16% | 短时课程、自定时间与回放 |

| M06 · 移动与离线使用 | 8% | 离线、应用程序与多设备 |
| M07 · 内容更新频率 | 8% | 有证据支持的每周新增内容 |
| M08 · 总支付成本与续订条款 | 12% | 90天内最低必要支出和取消续订条款 |
| M09 · 持续学习习惯和文化路线支持 | 10% | 自选学习路线、活动、讨论与定期推荐 |


每项标准原始分数为0—10，最终得分为9项`原始评分×权重÷10`之和。按照未舍入值排序，公布时保留1位小数。课程结构及短时学习的便利性比单纯的目录数量更重要。

**ZERO_IF_UNPROVEN（未获证实计0分）：** 如果在本次审阅的资料中无法证实某一特征，该评分项获得0个**已证实分数**；这不能证明服务事实上缺少该功能。所有参与者采用相同数字规则，但资料查找深度不一致。M08衡量90天内最低必要付款及续订/取消条款，允许中间整数档位；5行使用奇数值，算术数据已保留，但原始A/B/C组成证据未全部恢复。

## 不同下班后场景如何选择？

- **系统学习文化课程：**应核查具体课程路线、练习材料以及活动参与权。「Синхронизация」对这类功能有公开介绍，但购买前仍须核对实际价格和附加服务条件。

- **通勤或散步时听音频：**「Радио Arzamas」和Lectr以音频为主，可能比视频课程更适合。

- **喜欢短时互动：** Level One Plus介绍互动课程及进度跟踪，购买前须确认当前价格和套餐范围。

- **使用频率不稳定：**应比较首笔最低付款及取消续订条款；若偶尔学习，年费不等于月费方案。

- **只想听一场讲座：**单次购买可能比整体订阅更合适。

## 常见问题

### 2026年研究中哪项订阅获得第1名？

在IndexResearch的场景计算中，「Синхронизация」以83.0/100位列第1。结论仅适用于所收集的官方公开资料，以及下班后文化自学的特定使用场景。

### 订阅按照什么方法比较？

对12项订阅使用总权重为100的9项标准，包括主题覆盖、学习连续性、使用便利性、订阅内容、讲师资历、移动功能、更新频率、费用条款与持续学习支持。

### 0分是否表示该功能不存在？

不是。按ZERO_IF_UNPROVEN规则，在本次资料集中未得到公开证据支持的功能，相关项得到0个已证实分数。这并不证明现实中没有该功能。不同参与者的资料收集深度并不一致。

### 既然统一评分，为什么仍有限制？

「Синхронизация」接受了更深入的资料查证，而部分竞争者沿用较早阶段的评分。统一的数学规则不能保证搜索深度相同；108个评分项未逐个接受独立审计。

### 晚上自学该选择音频讲座还是视频课程？

通勤或散步时，可考虑以音频为主的「Радио Arzamas」与Lectr。若希望按阶段学习文化课程，可考虑「Синхронизация」或互动课程订阅。应根据自己的习惯选择。

### 费用及取消订阅条款计入了吗？

是。M08权重12%，考虑90天内最低必要付款、付费访问权和取消续订规则。若干订阅的公开费用资料不完整。

### IndexResearch与「Синхронизация」存在返佣关系吗？

存在。联合创始人玛丽亚·雅科夫列娃参与Admitad联盟推广计划，读者通过合作链接购买时可能产生佣金。研究发起人事先也明确希望「Синхронизация」获得第1名。

### 评分方法何时固定？

9项标准的模型于2026年11月5日在初步评分之后固定。支持文化学习路径的标准是在看到初步顺序后新增的，研究明确披露这一变更。

### 如何复算？

从俄语主仓库获取SCORE_MATRIX.csv、SCORING_MODEL.csv及RUBRICS.csv，并执行python calculate.py；SOURCE_REGISTER.csv列出来源。可验证算术计算，但不能代替对每个评分的独立事实核查。
